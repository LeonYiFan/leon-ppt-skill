# 内容与版式约定

## 阅读与证据

回看 PDF 原页核对文字顺序、图注、上下标、单位、剂量、样本量和统计量。对每项主要结果记录研究对象、分组与对照、关键方法、图号和面板、主要观察、作者结论和解释边界。引用补充结果前，先确认已取得相应材料。

临床研究突出人群、研究设计、终点、效应量、不确定性和偏倚。方法论文突出方法构建、验证和适用范围。综述突出证据组织、分歧和研究框架。讨论具体局限，并区分作者解释、汇报者判断与待验证建议。

## 页面结构

- 封面与文献信息包括中文主标题、英文原题、作者、期刊与年份，以及已核实的 DOI。
- 目录默认四部分。研究背景交代知识缺口，研究设计呈现研究对象与对照，研究结果顺着主要证据链展开，总结讨论写清贡献、局限与外推范围。
- 结果页用原图与简短解读回答比较了什么、观察到什么、证据支持到哪一步。密集图拆成多页，保留原始图区比例、轴标签、尺度尺与必要图例。
- 来源页脚写原文页码、章节或 Figure 面板。讲稿备注收录讲解要点、方法参数、统计说明和完整来源定位。后续研究建议注明为汇报者思考。

## 版式和可编辑性

宽屏 16:9，使用白底、蓝色信息带和章节线、深蓝标题、红色结论。封面右侧用 PowerPoint 几何形状装饰。内容页有页脚来源与页码。优先用简洁的平面布局，保持原生文本、形状、箭头和表格可编辑。原始照片、图版和缺少完整数值的数据图可使用图像对象。默认字体是 Microsoft YaHei，跨平台检查时注意字体替换会影响换行。

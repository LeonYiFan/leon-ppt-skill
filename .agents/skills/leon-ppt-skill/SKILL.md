# 蓝白学术汇报模板

沿用 16:9 白底蓝字、结论式标题、红色箭头要点、图或卡片、灰底总结条。图号、页码和来源说明写进演讲者备注，内容页省去页脚来源小字。生成时去除模板中的徽标、署名和机构标识。带机构字样的章节照片用同位置、同轮廓的蓝色几何图形替换。

## 资产

| 资产 | 角色 | 用法 |
|---|---|---|
| `assets/template-deck.pptx` | 8 个页型原型（空白化、形状已命名） | 构建入口。`scripts/build_report.py` 从这 8 页克隆出新页，所以新页天生带着模板的标题、要点块、总结条、卡片 |
| `assets/example-plan.json` | 12 页可跑的完整 plan（封面→致谢，八种页型都用上） | 写 plan 时照着改；它就是这套模板的密度与语气样本 |
| `assets/component-example.json` | 可跑的组件示例 | 展示八种可编辑结构及填充方式。示例内容为演示数据 |
| `assets/portable-library/` | 匿名蓝白整页原型、原生组件及可搜索版式 | 随技能安装，支持按内容匹配、A/B/C 预览和匿名目录对象复用 |
| 本地原生素材库 | 可选参考 | 已配置的本地库可通过 `--native-library` 连接 |
| `assets/summary-bar.png` | 灰底总结条底图（已按原页裁好） | 手工补页时直接用；用原型克隆则不需要 |

原型页顺序：`cover(0) agenda(1) divider(2) bullets(3) table(4) cards2(5) triple(6) thanks(7)`。

## 选用版式和组件

- 整套的视觉基准采用新版 GUT 文献答辩与指南项目答辩。文献问题、证据和结论优先参考前者，任务拆解、技术路线及计划优先参考后者。布局、相对比例和源页索引见 [两份主参考的版式](references/style-sources.md)。
- 在 plan 顶层开启 `"prefer_native": true`。证据和三栏页根据实际图幅、字体度量及槽位容量选版。方法配图、双图夹指标、分轨路线等结构按实际信息关系指定 `native_auto`。需要更细的手工原稿查询时连接已配置的本地库。[原生页型和组件](references/native-library-workflow.md)
- 关键内容页有多个适配版式时，提供 2–3 个可编辑备选。A 使用推荐版，合适时优先选择 GUT 或指南结构。B、C 展示其他适配构图，按需补入 KW16 等组件。按用户选择锁定对应版式并重建。用户要求直接出稿时使用推荐版。[生成与确认备选](references/native-library-workflow.md#生成与确认备选)
- 已配置版式容量不足或缺少所需构图时，用 `make_native_catalog.py suggest` 按图数、最小图幅、表格及文字槽位找候选。再用 `search --slots` 核实对象位置和容量，用本次文字、图片和数据填充 `native` 或 `native_components`。目录里的示意图位需用本次原图填充。[搜索并填充匿名版式](references/native-library-workflow.md#搜索并填充匿名版式)
- 分点、图卡和总结条共用清楚的对齐线。原生证据页按实际分点行数抬高或降下图卡，再用原图长宽比决定单卡、并列或上下排。双图和图—指标—图的短分点优先用约 22 pt，图卡在可读范围内略缩，保持同组卡片的顶线、底线和标题齐平。优先收紧卡片空白，原图按原比例放置。组别、样本和读数是并列证据时，填 `evidence_cards` 自动生成浅蓝对照卡。
- GUT 和指南候选均无法承载时，按需使用 KW16 的四阶段卡片、并列三卡、双侧对照、六支证据归纳或阶段检查矩阵。只把配置过的可编辑几何放入蓝白正文区，文字和数据来自当次材料。[KW16 结构参考](references/kw16-sources.md)
- `component.intent` 继续提供合适的通用结构。没有可用的整页或原生组件时可按 [自动选版与美化](references/primary-layouts.md) 生成，或沿用平实的原图页。

文字放不下时不用手改字号：`fill_text` 会用真实字体（微软雅黑 / Arial / Times）量一遍，
超框才把该框整体缩到放得下（最多缩到原来的 70%），并在构建结束时打印
`自动缩字 T_Title: 44 pt -> 33 pt`。看到这条提示，优先把话写短，别靠缩字将就。

## 何时用、默认交付

- 入口句式：`用 $leon-ppt-skill 把“论文.pdf”做成汇报`。
- 也接受：本地 PDF/附件、DOI 或链接、明确的文献目录、一组实验数据加图；用户指定的时长/页数/侧重点优先。
- 默认每篇一个 PPTX，命名 `年份_主题_文献汇报.pptx`，不覆盖同名文件；批量任务先按题目和 DOI 去重，再给目录。
- 页数服从证据量和时长，不凑页。经验值：15 分钟 ≈ 20–26 页，20 分钟 ≈ 28–34 页，30 分钟 ≈ 40–50 页。

## 工作流

1. **读源材料**。论文要读全文、Methods、主要图与图注、补充材料；有审稿意见或作者说明时一并读，用来补方法学动机。记录每个结论的出处（页/图/表/章节）。
2. **抽原图**。`scripts/extract_figures.py` 从 PDF 导出面板 PNG，使用 `--crop` 和 `--provenance` 留存 PDF 页、面板、裁切框与 SHA-256。**不要重绘、不要生成**科学图。原文给全可核对数值时可重建原生图表。
3. **写匿名 page plan**。按 [page plan 格式](references/page-plan.md) 写每页的标题、要点、总结、备注图源和讲稿。填写 `audit.figure_sources`，将本次资料中应剔除的姓名和单位写入仅限本地的 `audit.identity_terms`。引用用期刊、年份、DOI、章节或图号。检查原图的可见徽标和署名，必要时从源图物理裁掉身份区域并保留数据；无法分离时用可核验的文字摘要。
4. **构建**：
   ```text
   python scripts/build_report.py --plan plan.json --output output/xxx.pptx --manifest delivery.json
   ```
   脚本对「卡片数 ≠ 原型栏数」「要点超过 3 条」「表格行列数与原型不符」等直接报错，不会静默排版错。
5. **渲染并优化**。将 `delivery.json` 传给 `render_powerpoint.ps1 -FitManifest`。PowerPoint 只读渲染独立副本，比较排版后文字的四边与文本框及所属卡片安全区。越界页修到通过，并逐页看导出的 PNG，核查分点字号、末行到蓝色图卡标题的间距、同组卡片边线、放映时的图内字号和可见身份标识。逐页调间距时保留封面、目录和章节页本身的留白。优先调整槽位、缩短文案或拆页，保留主参考的字体层级。
6. **验收实际成品**。`python scripts/check_deck.py output/xxx.pptx --manifest delivery.json`。核对原图字节、输出对象及实际演讲者备注中的来源，检查包内身份信息、已知徽标和嵌图元数据。未登记的图内徽标或姓名须靠逐图和逐页视觉核查。按用户指定的模型与档位复核，并记录完成情况。
7. **交付**：给文件链接 + 影响使用的必要说明（缺哪张图、哪页证据弱、时长建议）。

## 风格铁律（改一处就会看得出不是这套模板）

- **标题是结论，不是主题**。「机器学习模型比较：随机森林综合表现最佳」而不是「模型比较」。一句话，尽量 ≤ 20 字，可带一个冒号。
- **要点 2–3 条，每条一行**（≤ 46 字）。每条里**只有一个**关键数字/短语标红。超过 3 条就拆页。
- **底部总结条必写**，一句话，把本页讲成对听众有用的判断，其中关键词标红。这是模板的签名元素，不能省。
- **每张图都有出处**。正文或补充图号、页码和表号写在演讲者备注。图卡标题和必要的读图说明继续用可编辑文字。
- **一页一个结论**。图太密就拆页，不缩成读不出坐标轴的小图。
- 卡片标题、章节页、封面和致谢沿用蓝白模板的布局、字体与配色。

## 语言：像本人在讲

- **先给判断**。标题就是结论，要点第一句就是结论；不要「我们研究了…，结果显示…」。
- **不用「不是 A，而是 B」**。这是最像机器的一句式，中文汇报里听着像演讲。直接说 B：
  「影像能看清时已属晚期，**早期判别缺的是分子依据**」。
- **不用「不仅…更是…」「既…又…」凑排比**。三条并列必须是三个真正平行的事实；凑不满就拆页或删。
- **删提示语**。「值得注意的是」「综上所述」「不难发现」「本文将」删掉后句子照样成立，
  说明本来就不该在。
- **不用空泛动词**。赋能、助力、抓手、闭环、生态、全方位、多维度，一律换成具体动作。
- **不用无数据的效果词**。「显著提升」写成「AUROC 从 0.86 升到 0.96」；原文没数字就写「未报告」。
- **保留限定词**。「提示／支持」不写「证明」；「未见显著差异（P=0.207）」不写「两组相同」；
  「校正后仍显著」不写「排除混杂」。
- **一处红字**。一条要点只标一个数字或短语，整句标红等于没标。
- **总结条只说一次**。它是本页的判断，不是标题复述，也不是要点小结。
- **备注允许口语**。「【讲】这页先说结论，再说凭什么」，讲稿不必书面语。
- 数字带单位和区间：`AUROC 0.961（95% CI 0.936–0.983）`、`P＜0.001`、`n=124`。

交稿前通读一遍，问一句：这句话换到别的论文里是否也成立？成立就删。
`check_deck.py` 会扫上列套式，命中只作提醒，改不改由判断决定。

## 三种声音

备注里写清楚谁在说话，被追问时不会混：**作者结论 / 本页观察 / 汇报者建议**。
正文只留作者结论与本页观察；建议、猜测、后续设想放备注。

## 图片规则

- 来源优先级：正文 Figure ＞ 补充 Figure ＞ 正文表格重绘 ＞ 原文截图。
- 裁剪必须保留：面板字母、坐标轴与刻度、图例、显著性标注、比例尺。
- 一张图拆多个面板时注明原 Figure 与面板；**不要把不同实验拼成一张图**误导听众。
- 图内英文标签可以保留，中文解读放在图外用可编辑文本框写。
- 图看不清就换更大的版式或拆页，不放大到模糊。

## 可编辑性

- 标题、要点、总结条文字、卡片标题、表格、流程框、色块都必须是原生对象；图片可以是图片（原图内部数据不承诺可逐项编辑）。
- 不整页截图、不整页转成图片、不把文字烧进图里。
- 表格用原生表格，表头深蓝白字、隔行浅蓝（`scripts/ppt_template.py` 的 `style_table`）。

## 组装与检查

- 常规骨架：封面 → 目录 → 章节页 → 内容页（背景/设计/结果/讨论，按需要增减）→ 章节页 → 总结 → 致谢。综述、临床研究、方法学论文各自调整，不硬套动物/细胞实验格式。
- 交付前必查：残留样例文字（`check_deck.py`）、占位文字、要点溢出、图能否读、演讲者备注内是否有图源、幻灯片上有无多余的页脚来源。
- 页数、时长与「讲/跳」建议一并说明：页数超过「时长 × 1.7」就要提醒，并给出主讲/备用分组。

## 禁止

- 生成稿及文档属性中禁用徽标、个人姓名、单位名称和联系方式。完整输入论文和带标识的参考素材用于本地查阅。
- 学术内容从本次材料中核对，版式参考仅提供布局和组件。
- 不写未核对的样本量、单位、统计量、影响因子；原文没写的标「未报告」。
- 不编造图、不用生成图替代实验图、不把「未见显著」写成「相同」。
- 不引入模板外的配色与字体，保留模板的总结条。

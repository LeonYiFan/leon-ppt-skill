# 文献汇报 Paper Report

使用 [蓝白空白模板](assets/paper-report-template.pptx) 为指定论文制作中文 PowerPoint。可接受本地 PDF、附件、DOI 或论文链接。目标论文不明确或无法取得制作所需的全文时，向用户索取缺失信息。页数和讲述节奏按论文证据量及用户指定的时长安排。

## 从论文到幻灯片

1. 精读全文、图注及可用补充材料。记录论文信息、研究问题、对象与分组、方法、关键结果、局限与来源位置。回看原文核对样本量、单位、效应量和统计方法。对重要但未报告的信息注明未报告。
2. 按 [内容与版式约定](references/report-guide.md) 组织封面、文献信息、目录、研究背景、研究设计、研究结果、总结与讨论、致谢。按研究类型调整内容。每张结果页聚焦一条有图文依据的结论。
3. 原始科研图来自本次输入论文及已核查的补充材料。嵌入前核查徽标、姓名、单位与联系方式，裁掉身份信息并保留比例、数据标签和关键图例。无法分离时，用有出处的文字概述。有可靠原始数值时可重绘可编辑图表。用可编辑的标题、正文、表格和逻辑图讲清证据，保持作者结论与汇报者解读各自可追溯。
4. 按 [制作与检查](references/build-workflow.md) 创建 PPTX。使用附带脚本时，先按 [数据格式](references/content-format.md) 整理 `report.json`。资料只读，构建和渲染在用户工作区完成。蓝白配色、蓝色文献信息带、章节编号、页眉蓝线和红色结论使用模板或生成器的现成布局。
5. 逐页检查图像可读性、引用定位、文字溢出、遮挡和可编辑性。核查正文、表格、备注、图片及文件属性中的匿名化情况。论文出处使用期刊、年份、DOI 和图表号。讲稿备注记录必要的方法、统计与结论边界。核对幻灯片与实际论文，清理占位信息。渲染可用时检查每页渲染结果，交付时说明影响使用的验证限制。

默认每篇论文输出一个 `年份_主题_文献汇报.pptx`，放入当前工作区 `output/`，避免覆盖已有文件。用户明确指定的时长、页数、格式和重点优先。

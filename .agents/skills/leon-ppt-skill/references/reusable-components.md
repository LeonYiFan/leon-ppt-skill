# 可复用组件

组件位于内容页正文区。标题、短蓝线、要点和灰色总结条由原型提供，来源写入演讲者备注。下表为八种通用组件。首选的答辩组件、`intent` 自动选版和美化见 [主参考布局](primary-layouts.md)。

| `layout` | 项数 | 什么时候用 | 推荐字段 |
| --- | --- | --- | --- |
| `flow` | 2–4 | 每步给下步提供输入，例如筛选、复核、独立验证 | `title` 写动作，`body` 写输入及输出，`tag` 可写阶段 |
| `compare` | 2 | 两组、两队列或两方法需要等权对照 | 两栏使用同样的指标顺序，`tag` 写组别或比较前提 |
| `matrix` | 4 | 四项可以换位置的证据或四个分类单元 | `title` 写维度，`body` 写本项观察；有两个分类变量时在标题中写明取值 |
| `timeline` | 2–5 | 要讲清已知的观测时点、随访或事件顺序 | `tag` 填日期、相对时间或随访点；默认等距，备注写明实际间隔 |
| `evidence` | 2–3 | 把证据及解读、风险及应对等按行对应 | `title` 写观察或风险，`body` 写范围或应对；真实原图可以放在同页独立图框 |
| `milestones` | 2–4 | 逐项呈现阶段交付或验收状态 | `title` 写可交付结果，`tag` 写期限或状态，`body` 写验收依据 |
| `roadmap` | 2–3 | 讲工作阶段、各阶段任务与对应产出 | `title` 写阶段，`tag` 写产出，`body` 写任务。复杂分轨按 [主参考](style-sources.md) 对齐各轨 |
| `criteria` | 2–4 | 列纳入、分层、排除或验收的判定条件 | `title` 写条件，`body` 写口径，`tag` 写阈值及单位 |

真实时间填入时间轴，只有逻辑先后时用流程。有待完成的工作阶段用路线图，验收结果及期限用里程碑。并列比较用同口径双栏，风险与应对用对齐行。需要读完整原图时用普通 `bullets` 原图页。完整比较表继续使用 `table` 原生表格；证据行可呈现要点和口径解读。

## 放入页面

以下字段写在已有 `type: "bullets"` 页里，与 `title`、`bullets`、`summary`、`source`、`notes` 同级。

```json
{
  "component": {
    "layout": "flow",
    "items": [
      {"title": "初筛", "body": "按预先定义的条件判定可入组样本"},
      {"title": "复核", "body": "由独立读片者复核分歧", "tag": "冻结名单"}
    ]
  }
}
```

- `title` 必填。`tag` 和 `body` 可省略。标题和标签填单段，正文可用换行。需要标红时每字段至多用一对 `**…**`，整页只强调有辨识作用的词或数。
- 组件页最多两条要点。填总结、来源和备注。科学来源写本次材料的章、图、表、页或 DOI，构图参考页码留在这份索引及其来源说明中。
- 默认占满正文区。需要在同页放图时，`component.box` 和 `figures[].box` 均以 `[x, y, w, h]` 表示厘米位置。可用范围 x=1.24–32.59、y=5.80–16.25；组件最小 12 × 6 cm，使用独立且不重叠的图框。例如左图 `[1.24, 5.8, 16.5, 10.45]`，右侧证据行 `[18.29, 5.8, 14.3, 10.45]`。图中文字读不清时拆页或缩短解读。
- 组件仅生成可编辑文字和形状。图片取自本次材料，具名科学原图按原有匿名流程核对、裁剪及标注。条目数、文字或范围超出时调整计划后再构建。

完整填法见 [组件示例](../assets/component-example.json)。源页依据见 [两份主参考](style-sources.md) 和 [KW16 结构参考](kw16-sources.md)。

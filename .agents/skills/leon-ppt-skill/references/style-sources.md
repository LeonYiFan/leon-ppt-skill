# 两份主参考的版式

“文献答辩”指本地 55 页学术答辩稿，“项目答辩”指本地 42 页指南项目答辩稿。下文页号均为源 PPTX 的实际页序。两份参考统一采用 33.87 × 19.05 cm 画布。文献与实验结果页主要参考文献答辩，研究任务、技术路线和项目安排主要参考项目答辩。

## 保持两份主参考共有的样式

- 封面保留蓝色横带和白字主标题。目录用竖排标题、四个等距编号和对应章节名。只有汇报问题真正转换时才加章节页，章内连续展开同一类方法时可加小型进度标签。对应文献答辩第 1–3、8、14–18、38、51 页，项目答辩第 1–2 页。
- 文献答辩常用标题盒约 x=1.07 cm、y=0.51 cm，28–30 pt 深蓝（#173467），下方有短蓝线。正文深墨（#111820），两条要点多从 y≈2.6 cm 起，约 18–22 pt，关键值或限定词用红字。深蓝窄标题带、白底内容、浅蓝边线组成证据面板。原型已划定灰底总结条，来源放入演讲者备注，内容密度以实际放映时能读清为准。
- 项目答辩中上位任务名位置固定，源标题常用 36 pt、#122A5C。复用时保留技能原型的标题盒，在内容区用浅蓝横带或深蓝窄标题分隔工作基础、研究内容、技术路线和产出。红色集中于关键判断或验收值，复杂任务优先拆成总览和分轨两页。对应项目答辩第 10–21 页。
- 先讲比较关系，再摆图。并列的组、时期或任务使用一致的对齐线，表示先后或依赖的连接线只在关系确实存在时使用。单图能支撑结论时留大图，关键原图的面板字母、轴、图例、统计标记和比例尺优先于面板数量。

## 根据文字和图幅调比例

- GUT 40、41、46、52 的证据页都让正文要点靠近下一行蓝色标题带。只有一条分点时把卡片整体上移，保留清楚的短间隔。两条分点按实际行高落卡片，避免固定沿用三行版的大空白。
- GUT 41 的图—指标—图、GUT 52 的双图和 GUT 21/26 的不等宽双图，统一卡片顶线、底线、标题高度和栏间距。对短文短图可适度收窄、收低卡片，正文优先使用易读的 20–22 pt。优先删除卡内过量留白，再等比例缩放原图。宽幅与竖幅混排时按各自轴标和图例的可读尺寸选卡宽。图卡与总结条之间留出适度间隔，来源放入演讲者备注。
- 队列、样本和效应是并列证据时借 GUT 52 的对照卡和 GUT 41 的浅蓝指标块。左栏放短标签和读数，右栏放原图。超宽的原图改用上方并列文字卡、下方整行图卡。指南第 16 页的箭头只借给有真实先后的两段方法。

## 按证据关系取结构

| 场景 | 布局与填充 | 对应源页 |
| --- | --- | --- |
| 原始证据缩略与项目全貌 | 约三分之一左列给当前材料中的来源总览，右列排 3–4 个纵向阶段。每阶同一阅读顺序，先名称、再行动、最后产出。来源总览图必须放映可读，放不下可用原生文字和形状表达 | 文献答辩 7 |
| 同类方法连续解释 | 第一行放 2–3 段导航，只强调当前方法；正文约 44:56。左侧放方法结果原图，右侧用编号说明各步骤或判断依据。跨页固定导航与左右边界，讲单一方法时省去导航 | 文献答辩 14–18 |
| 筛选、输出、独立验证 | 左右两侧分别是筛选依据与独立验证，中间窄列只放筛出的对象或最关键的数字。视觉权重约 1:0.55:1.2。仅当筛选到验证有明确步骤时使用箭头 | 文献答辩 19 |
| 原图证据与校正结果 | 主侧约占 2/3，给曲线或多个放映可读的同类面板；副侧约占 1/3，给调整结果的可编辑表格或两行解释。统计检验、协变量、样本口径放正文或备注中相邻的位置 | 文献答辩 26 |
| 两组或两阶段的同条件证据 | 等宽面板，同一高度起笔。标题说明比较对象；图内沿用来源的坐标轴与图例，图外对齐可独立归因的读数。带多种分层时用共同的证据列与左侧行标签 | 文献答辩 22–23、27、43、46 |
| 图、指标、图 | 两侧图分别回答两个观测问题；中央窄卡稳定对齐，最多放两个带名称与单位的关键数。若两组口径各异，直接在所属面板写明比较范围 | 文献答辩 41 |
| 指标公式与上游步骤 | 上排 3–4 个原生小步骤框，下排用原生文本和矩形呈现公式及各项含义。每个项的方向、分母、归一化与原研究一致，限于原研究明示或可核验定义 | 文献答辩 47 |
| 发现总结 | 两个等权重模块分别写主发现与证据，每个模块可保留一张放得清楚的原图。灰条写共同的解释或应用边界 | 文献答辩 52 |
| 上位问题与分任务 | 上方一条问题或总体目标带，下方 2–3 个任务卡按同样顺序列问题、动作和产出。项目尚在计划时在卡中明确“拟开展”或“拟验证” | 项目答辩 7–9 |
| 多轨路线 | 各轨的输入、关键步骤和产出横向对齐。两轨不同方法时可给单侧更多空间；任务间确有共享输入或依赖时加连线。步骤过密时每一轨各占一页 | 项目答辩 13、16–17、20–21 |
| 指标、风险与日程 | 验收目标和证据按行对齐。风险与应对逐行对应。进度用共同时间轴配任务行和阶段条，保留真实起止；阶段条不承载详述 | 项目答辩 29–31 |
| 创新点与已有基础 | 简短类别标签对应一条可核对的创新内容。已有基础另起一组，优先给能支持预期任务的证据 | 项目答辩 33 |

呈现效应量时把队列、指标、单位和比较对象放在读数附近。预测模型区分训练、验证与独立外部验证。观察、机制解释和预期产出分别采用相称的结论表述。当科学图和旁边的解读卡需要争夺空间时，先缩减解读卡文案。

两份源稿只为本地选版提供结构依据。复用时从当前汇报材料重新填入正文、表格、图、数据和引文。用原生文本、形状、连线和表格重新组织，不导入源页母版、建筑照片、作者及平台介绍、徽标、隐藏对象、注释或图表工作簿。源稿第 53–54 页（文献答辩）和第 23–28、35–42 页（项目答辩）尤其含署名、肖像、单位或前期实验材料，按结构需求重建共用版式时也省去这些对象。科学证据继续使用本次材料的原图并在演讲者备注记录出处。

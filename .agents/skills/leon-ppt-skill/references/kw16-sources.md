# KW16 结构参考

本地材料别名为「KW16 合集」（524 页）和「KW16 第九套」（55 页）。页号按 PowerPoint 当前顺序从 1 计。已逐页浏览。第九套的 54 页与合集对应页的 432 × 243 渲染完全相同。剩余的第九套第 20 页对应合集第 190 页，仅底部注释有细微像素差异。引用其中一处页号即可。

| 要组织的内容 | 本地来源 | 在学术汇报中的用法 |
|---|---|---|
| 连续的研究步骤或采样时间 | 第九套 16／合集 143 | 用一条向右的细轴串起 3–4 个同宽节点。短标签写步骤、时间或样本，详细动作放在轴下。 |
| 两个研究组按相同时间经过不同处理 | 第九套 44／合集 424 | 将两条同向泳道上下排列，同一时间点垂直对齐。节点间距可等距表示流程阶段，比例时间轴必须与真实间隔一致。 |
| 两组的对照条件或对称论点 | 第九套 35／合集 347 | 用左右等宽模块及相同条目顺序，中心留白。红字点出差异，行间可用浅蓝辅助对齐。 |
| 三项平行证据或研究维度 | 合集 149 | 用三个等宽原生卡片，每栏放一个结论或证据类型。卡片抬头与图注同一对齐线，以灰色总结条收口。 |
| 同一问题的多条独立证据 | 第九套 50／合集 484 | 中心放共同问题，四周排 3–4 个证据标签。普通细线表示归属，按因果或时间方向绘制的箭头需有来源支持。 |
| 有交汇终点的多方法验证 | 合集 455 | 将输入放在最上方，中间并列方法模块，底部只留确实共同验证的终点。若方法各自回答不同问题，用平行卡片。 |
| 指标、基线或终点的同口径对照 | 第九套 20／合集 190 | 用深蓝表头、交替浅蓝行及浅色注释区。列标题写单位和组别，表下注释解释分析口径。冻结真实数据来源。 |
| 按阶段检查研究计划 | 第九套 21／合集 204 | 用可编辑表格和水平条形统一起止时间、分工及交付节点。只在有实际时间安排的课题页使用。 |

原始参考中可拆的几何元素是等宽卡片、胶囊标签、细线箭头、双泳道、矩阵和时间条。放入正文内容区，采用当前蓝白模板的字号、配色和总结条，图源写入演讲者备注；原生对象留给后续编辑。剔除商务导航、模板商标、照片、奖状、水印、假数据和占位文字。论文结果页仍用任务论文的实证原图。

四阶段卡片、并列三卡、同口径对照、六支归纳和四阶段检查矩阵已配置成 [可自动填充的局部组件](distilled-layouts.md#kw16-补充组件)。其余结构可在全库搜索后手工用 `native_components` 引用已核对的原生对象。

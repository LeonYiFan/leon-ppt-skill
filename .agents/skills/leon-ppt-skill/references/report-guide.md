# 版式与语言规范

以下数值为既有蓝白模板的几何与样式基准。按汇报类型选取构图时，参考 [两份主参考的版式](style-sources.md) 和 [可复用组件](reusable-components.md)。

## 1. 画布与字体

- 画布 **33.87 × 19.05 cm**（12192000 × 6858000 EMU），16:9。所有位置以厘米给出。
- 中文 **Microsoft YaHei / 微软雅黑**；西文与数字 **Arial**；封面英文题名、页脚期刊信息用 **Times New Roman**。
- 字号（pt）：封面主标题 44、章节页标题 48、页标题 28–29.4、要点约 20–22、卡片标题约 18–20、总结条 18。

## 4. 特殊页

- **封面**：上部浅灰、中部蓝色扇形带（图片），白色 44 pt 主标题压在带上，下方为英文题名和可选的期刊与 DOI 页脚。
- **目录**：左侧竖排「汇报提纲」，右侧 `01`–`04` 蓝色方块 + 章节名，共四部分。
- **章节页**：左侧约 16.79 cm 通高，生成稿在原照片位置用蓝色几何块。右侧为深蓝 48 pt 标题。
- **致谢**：蓝底城市剪影带 + 「衷心感谢各位老师！敬请批评指正！」，省去汇报人和单位。

## 5. 页型选择

| 页型 | 什么时候用 | 原型 |
|---|---|---|
| `bullets` | 纯文字论证、背景、结论 | 3 |
| `table` | 需要并列比较（手段/敏感度/分组/基线） | 4 |
| `cards2` | 两组对照：两个队列、两种方法、模型前后 | 5 |
| `triple` | 三条并列原则 / 三张连续面板 | 6 |
| `divider` | 章节切换 | 2 |
| `cover` / `agenda` / `thanks` | 结构页 | 0 / 1 / 7 |

要点块下如果只放一张大图，用 `bullets` 并通过 `figures` 给显式矩形；不要为了塞图去改卡片结构。

## 6. 文案写法

标题：

- ✅「机器学习模型比较：随机森林综合表现最佳」
- ✅「阈值选择：两队列准确率之和最大处为 0.65」
- ❌「模型比较」「关于阈值的一些讨论」「结果 3」

要点（每条一行，只标一个红点）：

- ✅「在两组演示数据中，**已达到预设准确率**。」
- ❌ 把整条都标红；❌ 一条塞三个结论；❌ 超过 3 条。

总结条（一句话判断，不是复述标题）：

- ✅「在同一批演示数据中，**加入两项特征后准确率更高**。」
- ❌「本页介绍了消化酶比较的结果。」

数字与边界：

- ✅ `AUROC 0.917（95% CI 0.855–0.965）`、`P＜0.001`、`n=51`
- ✅「健康与肝病对照**未见显著差异**（P=0.207）」
- ❌「两组完全一致」「证明与炎症无关」「模型非常准确」

### 6.1 机器腔改成汇报腔

幻灯片一句话占一屏，套话会立刻暴露不是本人在讲。四组对照，左边一律不要：

| 不要 | 要 |
|---|---|
| 缺的**不是**检测手段，**而是**分子层面的判别依据 | 影像能看清时已属晚期，**早期判别缺的是分子依据** |
| 本研究**不仅**比较了 AUROC，**更是**做了校准与决策曲线 | 除 AUROC 外，本页还看**校准曲线与决策曲线** |
| **值得注意的是**，验证集效能略有下降 | 验证集 AUROC 从 0.961 降到 **0.912** |
| 该评分**显著提升**了诊断效能 | 验证集 AUROC **0.912**，三种参照均更低（DeLong P＜0.05） |

四条判据，写完自己过一遍：

1. 删掉「值得注意的是／综上所述／不难发现」后，句子是否照样成立？成立就删。
2. 这句换到另一篇论文里是否也成立？成立就是废话，删。
3. 有没有数字？没有数字的效果词（显著、大幅、极大）一律换成数字，或写「未报告」。
4. 有没有把话说满？把「证明」降成「提示／支持」，把「相同」降成「未见显著差异」。

### 6.2 会被 `check_deck.py` 扫到的写法

`不是…而是`、`不仅…更是`、`至关重要`、`赋能/助力/抓手/闭环/生态/全方位/多维度`、
`众所周知`、`值得注意的是`、`综上所述`、`本文将`、`旨在/以期`、`显著提升`、
破折号、多个感叹号。命中只是提醒，不自动改；但每一处都该有个交代。

注意：这些词出现在引用的原文标题、专有名词里不算。

## 7. 备注模板

```text
【讲】这一页先说结论，再说凭什么。
【关键数】AUROC 0.961 / 0.912；敏感度 91.1% / 84.9%。
【若被问】验证集参与了阈值选择，后续需在独立队列锁定阈值复核。
```

## 8. 交付前检查清单

- [ ] 每页标题是结论句；
- [ ] 要点 ≤ 3 条、每条 ≤ 46 字、只有一处红字；
- [ ] 内容页有总结条，图源写在演讲者备注；
- [ ] 每张图能读出坐标轴、图例、面板字母；
- [ ] 确认正文、表格、备注、图片和文档属性中的匿名化情况，并用 `check_deck.py` 检查旧样例词；
- [ ] 每页有备注，备注里区分了作者结论与汇报者建议；
- [ ] 页数与时长匹配（经验上限：时长分钟 × 1.7 页）。
